# Database Schema

The complete Prisma schema is implemented in `apps/api/prisma/schema.prisma`.

Major entities:

- Users
- Roles
- Permissions
- Students
- Teachers
- Classes
- Games
- Game Categories
- Homework
- Achievements
- Scores
- Reports
- Audit Logs
- Notifications
- Settings

The seed script creates all class groups, 12 learning categories, 225 reusable games, demo users, role permissions, and starter achievements.
