# Sprint Plan

## Sprint 1: Foundation

- Monorepo setup.
- Database schema.
- Auth, RBAC, audit logs.
- Seed roles, classes, categories, games, demo users.

## Sprint 2: Student Experience

- Class selection on first login.
- Game browser and game player templates.
- Student progress, stars, badges.
- Homework submission.

## Sprint 3: Teacher Experience

- Assigned class dashboard.
- Homework creation and review.
- Score analytics.
- Students needing attention.

## Sprint 4: Admin Experience

- User management.
- Teacher permissions.
- Game approval and release calendar.
- Platform analytics.

## Sprint 5: Reports and Hardening

- CSV, Excel, PDF exports.
- Rate limiting and security review.
- Accessibility testing.
- E2E regression suite.
- Production deployment.
