# Feature Breakdown

## Phase 1

- JWT authentication and refresh tokens.
- RBAC roles and configurable permissions.
- Class group setup.
- Game catalog with approval workflow.
- Student dashboard and game browser.
- Homework assignment and submission.
- Basic reports.

## Phase 2

- Game authoring UI.
- PDF, Excel, CSV exports.
- Advanced teacher analytics.
- Certificate generation.
- Notification preferences.
- File attachments.

## Phase 3

- Android and iOS apps.
- AI story generator.
- AI quiz generator.
- Voice narration.
- Attendance tracking.
- Fee management.
- Multiple branches.
- Video learning.
