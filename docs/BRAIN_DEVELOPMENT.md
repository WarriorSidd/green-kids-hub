# Brain Development Program

The brain development section uses widely adopted early-learning activity patterns: memory matching, pattern recognition, observation, visual discrimination, sequencing, spatial reasoning, logic puzzles, decision-making, sustained attention, and problem solving.

## Group A: Senior KG and 1st Standard

- Large visual memory cards with familiar objects.
- Shape and color pattern continuation.
- Spot-the-difference observation scenes.
- Simple maze and left-right spatial tasks.
- Emotion choice stories with two or three options.

## Group B: 2nd and 3rd Standard

- Grid recall with increasing complexity.
- Sequence challenges using numbers, days, stories, and routines.
- Multi-attribute sorting by size, shape, category, and function.
- Logic elimination puzzles with visual hints.
- Timed focus games with short rounds and breaks.

## Group C: 4th and 5th Standard

- Strategy memory with distractors.
- Spatial rotation and map-reading tasks.
- Multi-step logic puzzles.
- Decision trees and consequence reasoning.
- Debugging-style concentration games.
